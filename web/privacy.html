개인정보처리방침

시행일 2026년 10월 28일 · 대상: 일정관리기(PC 프로그램과 웹앱 https://jyplanner.vercel.app)

일정관리기(이하 "앱")는 사용자가 자기 구글 계정의 시트·드라이브·캘린더·할일을 한곳에서 보고 관리하도록 돕는 업무용 도구입니다. 앱은 사용자의 정보를 판매하거나 광고에 쓰지 않으며, 앱을 쓰는 데 필요한 만큼만 다룹니다.

1. 앱이 받는 구글 권한과 쓰는 곳

계정 이메일 (openid · email)누구로 로그인했는지 보여 주고, 계정이 바뀌면 앞 계정의 자료를 지우는 데 씁니다.
구글 시트 (spreadsheets)사용자가 정한 고객관리 시트를 읽어 목록·주간 요약을 보여 주고, 사용자가 화면에서 고친 칸만 그 시트에 씁니다.
구글 드라이브 읽기 (drive.readonly)사용자가 정한 폴더의 서류·견적서 파일을 보여 줍니다. 파일을 바꾸거나 지우지 않습니다.
드라이브 앱 전용 폴더 (drive.appdata)앱 설정(시트 주소·서류 폴더)을 사용자 드라이브의 앱 전용 숨김 폴더에 저장해 다른 기기에서도 이어 씁니다.
구글 캘린더 읽기 (calendar.readonly)다가오는 일정을 홈 화면에 보여 줍니다.
구글 할일 (tasks)할일을 보여 주고, 사용자가 누를 때 할일을 추가하거나 완료로 표시합니다.

2. 저장하는 곳

  • 사용자의 기기 — 화면을 빨리 띄우려고 받아 둔 목록·일정은 사용자의 브라우저(또는 PC) 안에만 저장합니다.
  • 로그인 유지 쿠키 — 웹앱은 다시 로그인하지 않도록 구글이 준 갱신 토큰을 암호화하여 사용자 브라우저의 쿠키(화면 코드가 읽을 수 없는 HttpOnly·Secure 쿠키)에 둡니다. 앱 운영자의 서버나 데이터베이스에는 사용자의 구글 자료나 토큰을 저장하지 않습니다.
  • 로그인 서버(Vercel)는 쿠키의 토큰으로 구글에서 1시간짜리 접근 토큰을 받아 사용자에게 돌려주는 일만 하며, 구글 자료 내용을 받거나 보관하지 않습니다.

3. 제3자 제공

앱은 사용자의 정보를 누구에게도 팔거나 넘기지 않습니다. 사용자가 [복사]·[보내기] 단추로 직접 다른 앱(카카오톡 등)에 붙여 넣는 경우만 예외이며, 그것은 사용자가 고른 동작입니다.

4. 구글 사용자 데이터 정책 준수

구글 API 에서 받은 정보를 쓰고 다른 앱으로 옮기는 것은 Google API 서비스 사용자 데이터 정책과 그 제한적 사용(Limited Use) 요건을 따릅니다. 앱은 구글 사용자 데이터를 광고에 쓰지 않고, 사람이 읽지 않으며(사용자가 요청한 경우·보안·법적 의무 제외), AI 모델 학습에 쓰지 않습니다.

5. 보관 기간과 삭제

  • 웹앱 [정보] 탭의 [로그아웃] — 로그인 쿠키와 이 기기에 받아 둔 자료를 지웁니다.
  • 구글 계정의 서드파티 앱 액세스에서 "일정관리기" 권한을 없애면 앱은 더 이상 구글 자료에 접근하지 못합니다.
  • 로그인 쿠키는 마지막 사용 후 최대 400일이 지나면 브라우저에서 스스로 사라집니다.
  • 드라이브 앱 전용 폴더의 설정은 구글 드라이브 설정 → 앱 관리에서 지울 수 있습니다.

6. 보안

모든 통신은 HTTPS 로 합니다. 갱신 토큰은 AES-256-GCM 으로 암호화되며, 로그인 서버는 이 앱 주소에서 온 요청만 받습니다.

7. 바뀔 때

이 방침이 바뀌면 이 페이지에 시행일과 함께 올립니다.

8. 문의

개인정보 관련 문의는 구글 로그인 동의 화면에 표시된 개발자 지원 이메일로 보내 주세요.
