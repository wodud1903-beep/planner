# 업무자료검색 (kbsearch)

일정관리기(`python/`)에서 **자료검색 화면과 업무자료 빠른검색만** 떼어 낸 가벼운 프로그램입니다.
캘린더·할일·고객관리·고객정보·인사말·수당 계산은 없습니다. 일정관리기 코드는 건드리지 않았습니다.

| | 일정관리기 | 업무자료검색 |
|---|---|---|
| 화면 | 탭 여러 개 | **자료검색 한 화면** |
| 로그인 | 켜자마자 구글 로그인 | **로그인 없이 씀** — [동기화] 를 누를 때만 |
| 저장 위치 | 계정별 폴더 + 자동 동기화 | **이 PC 에만** (`%APPDATA%\KbSearch\`) |
| 회사 공통 자료 | 전용 스프레드시트 `업무자료` 탭 | **같은 시트·같은 탭 — 로그인 없이 저절로 받음**(켤 때·10분마다) |
| 내 메모 | 드라이브 동기화 묶음 | **같은 묶음의 `kb_mine.json` 칸** — 같은 계정이면 두 프로그램이 같은 메모 |
| 설정 | 여러 가지 | 시작 프로그램 · 화면 테마 · 빠른검색 단축키 **세 가지만** |
| 업데이트 | 묻고 업데이트 | **건너뛸 수 없음** — 업데이트하지 않으면 실행되지 않음 |

## 📥 직원용

1. 저장소 **Releases** 에서 `업무자료검색 kb-v…` 릴리스의 `업무자료검색.exe` 를 받아 실행합니다(설치 없음).
2. 찾을 말을 칩니다 — `신한 전자약정`, `ㅅㅎ ㅈㅈㅇㅈ`(초성) 모두 됩니다.
3. 오른쪽 **[본문 복사]**, 첨부는 골라서 **Ctrl+C**(또는 끌어서) → 카카오톡에 붙여 넣기.
4. 다른 프로그램을 쓰다가도 **Ctrl+Alt+F** → 빠른검색 창 → **Enter** 면 본문이 복사되고 닫힙니다.
5. 창을 닫으면 트레이로 내려갑니다(단축키가 계속 동작). 완전히 끄려면 트레이 아이콘 → **[종료]**.

### 회사 공통 자료는 저절로
- 관리자가 일정관리기(또는 여기)에서 고쳐 시트에 올린 공통 자료와 그 첨부(그림·PDF)가
  **로그인 없이** 따라옵니다 — 켤 때, 켜 둔 동안 10분마다(`config.KB_AUTO_MINUTES`),
  창이나 빠른검색을 열 때 5분 넘게 지났으면 그때도. 아래 줄에 `공통 자료 자동 받음 09:15` 로 보입니다.
- 시트를 **공개 CSV** 로 읽습니다. 시트가 지금처럼 **'링크가 있는 모든 사용자 — 뷰어'** 로 열려 있어야
  합니다(첨부도 원래 '링크가 있는 누구나 보기' 로 올라갑니다). 시트를 잠그면 자동 받기는 멈추고
  아래 줄에 알리며, 시트에 초대된 계정은 [동기화] 로 계속 받을 수 있습니다.
- 관리자가 **이 PC 에서** 고친 공통 자료가 아직 안 올라갔으면, 덮어쓰지 않으려고 자동 받기를 멈춥니다
  ([동기화] 가 올릴지 묻습니다).

### [자료 편집]
- **내 메모**는 누구나 로그인 없이 추가·수정합니다. 그림·PDF 첨부도 이 PC 에 보관됩니다.
- **회사 공통 자료**는 관리자 계정(`config.KB_ADMINS`)으로 [동기화](로그인)한 PC 에서만 고칩니다.

### [동기화]
- 처음 누르면 브라우저로 구글 로그인 → [허용]. 그다음부터는 누를 때마다 바로 동기화합니다.
- 하는 일
  - 회사 공통 자료: 시트 → 이 PC(저절로도 받지만 지금 한 번 더). 관리자가 이 PC 에서 고친 것이
    있으면 시트로 올릴지 묻습니다.
  - 내 메모: 이 PC ↔ 내 구글 계정. 일정관리기와 같은 메모라 양쪽에 다 나옵니다.
  - 이 PC 에만 있던 첨부를 드라이브(`업무자료` 폴더)에 올린 뒤 내보냅니다.
- 이 PC 에서 고친 것이 아직 안 나갔으면 단추가 **동기화 ●** 로 보입니다.
- 계정을 바꾸면 이 PC 의 메모를 비울지/합칠지 묻습니다. 아래 줄의 [로그아웃] 으로 로그인을 풉니다.

## 💾 저장 위치 `%APPDATA%\KbSearch\`

```
settings.json       테마 · 단축키 · 창 위치
kb_shared.json      회사 공통 자료(받아 둔 것). 없으면 이 PC 의 일정관리기 것 → 기본 자료
kb_mine.json        내 메모
kb_meta.json        동기화 상태(고친 것·지운 메모 제목·마지막 동기화 등)
kb_files\           첨부 캐시 (local-… 은 아직 안 올린 첨부)
google_token.json   [동기화] 로그인
update_state.json   업데이트 되풀이 막기 · update_log.txt 교체 기록
crash_log.txt       갑자기 꺼짐·멈춤 기록(다음에 켤 때 알리고 [기록 복사])
```

## 🔄 자동 업데이트 (관리자)

- 일정관리기와 **같은 저장소의 릴리스**를 쓰고, 태그 머리말로 가릅니다 — 일정관리기 `v1.21.1`, 업무자료검색 `kb-v1.0.0`.
- 켤 때와 켜 둔 동안 3시간마다 확인합니다. 새 판이 있으면 **받아서 바꾸고 다시 켭니다. 건너뛰기 단추는 없습니다**
  ([다시 시도] · [종료] 만). 인터넷이 안 돼 확인 자체를 못 하면 그냥 켜집니다(자료가 이 PC 에 있으므로).
- 새 판 내는 법
  1. `kbsearch/kbsearch/config.py` 의 `APP_VERSION` 을 올립니다(예: `1.0.1`).
  2. `kbsearch/CHANGELOG.md` 에 `## v1.0.1 — 제목 (날짜)` 절을 적습니다.
  3. 커밋 후 `git tag kb-v1.0.1 && git push origin kb-v1.0.1`
     → Actions(**Build 업무자료검색 EXE**)가 검사·빌드 후 릴리스에 exe 를 붙입니다.
  - 태그와 `APP_VERSION` 이 다르면 빌드가 멈춥니다(다르게 나가면 업데이트가 끝없이 되풀이됩니다).
  - 릴리스는 `make_latest: false` 로 나갑니다 — 일정관리기의 '최신 릴리스' 를 가리지 않게.
  - ⚠️ 릴리스는 GitHub 웹에서 손으로 만들지 말고 **태그를 밀어** 만드세요. 손으로 만들면 일정관리기
    빌드(`build-exe.yml` 의 `release: created`)가 함께 돌고, '최신 릴리스' 표시도 이쪽으로 넘어갈 수 있습니다.

### 서비스 끄기 — 업데이트로

`config.py` 의 스위치를 바꿔 새 판을 내면, 모든 PC 가 업데이트되면서 그대로 따릅니다.

| 스위치 | 끄면 |
|---|---|
| `SERVICE_ON = False` | 켜면 `SERVICE_OFF_MESSAGE` 안내만 띄우고 끝납니다(PC 시작 때는 조용히 끝남). 업데이트 확인은 계속하므로, 다시 켠 판을 내면 살아납니다. |
| `SYNC_ON = False` | 검색·편집은 그대로, [동기화](구글 로그인·시트·드라이브)와 공통 자료 자동 받기가 멈춥니다. 구글 쪽을 닫기 전에 이 판을 먼저 내세요. |

## 🧑‍💻 개발자

```bash
cd kbsearch
python -m pip install -r requirements.txt
python -m kbsearch            # 또는 python main.py  (/tray 를 붙이면 트레이로 시작)
python verify/run_all.py      # 검사 (화면 없으면 저절로 offscreen)
pyinstaller kbsearch.spec --noconfirm --clean   # dist\업무자료검색.exe  (윈도)
```

검사(`verify/`)는 가짜 구글로 시트·드라이브 요청을 흉내 내며, **일정관리기 묶음의 다른 칸을 한 글자도
바꾸지 않는지**와 **일정관리기의 실제 sync 코드가 우리가 쓴 메모를 받아 가는지**까지 확인합니다.
그래서 `python/planner` 도 함께 불러옵니다(읽기만).
