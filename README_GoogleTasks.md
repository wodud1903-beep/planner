# 구글 할일(Tasks) 연동 설정 안내

구글 Tasks는 캘린더와 별개 시스템이라, ICS로는 못 가져옵니다.
이 프로그램은 **구글 공식 API(OAuth)**로 Tasks를 직접 읽어옵니다.
아래 세팅을 한 번만 해두면 이후에는 자동으로 동작합니다.

소요 시간: 약 15~20분 (처음 1회만)

---

## 1단계 — 구글 클라우드 프로젝트 만들기

1. https://console.cloud.google.com 접속 (구글 로그인)
2. 상단 프로젝트 선택 → **새 프로젝트** → 이름 아무거나(예: `PlanManager`) → 만들기
3. 만든 프로젝트가 선택돼 있는지 확인

---

## 2단계 — Tasks API 사용 설정

1. 좌측 메뉴 → **API 및 서비스 → 라이브러리**
2. 검색창에 **`Tasks API`** 입력 → 클릭 → **사용** 버튼

---

## 3단계 — OAuth 동의 화면 구성

1. 좌측 메뉴 → **API 및 서비스 → OAuth 동의 화면**
2. User Type: **외부(External)** 선택 → 만들기
3. 앱 이름(예: `PlanManager`), 사용자 지원 이메일(본인 이메일) 입력
4. 개발자 연락처 이메일(본인) 입력 → 저장 후 계속
5. 범위(Scopes)는 건너뛰어도 됩니다 → 저장 후 계속
6. **테스트 사용자** 단계에서 **본인 구글 계정(gmail)을 추가** → 저장
   - ⚠️ 이 단계를 빠뜨리면 로그인 시 "확인되지 않은 앱" 오류가 납니다

> 테스트 사용자로 등록하면 "게시" 하지 않아도 본인 계정은 정상 동작합니다.

---

## 4단계 — OAuth 클라이언트 ID 만들기 (가장 중요)

1. 좌측 메뉴 → **API 및 서비스 → 사용자 인증 정보**
2. 상단 **+ 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
3. 애플리케이션 유형: **데스크톱 앱** 선택 ← 반드시 이걸로
4. 이름 아무거나 → 만들기
5. 팝업에 **클라이언트 ID**와 **클라이언트 보안 비밀(Secret)**이 나옵니다

## 5단계 — 프로그램에 입력

1. 일정관리기 실행 → 상단 **`구글 설정`** 버튼 클릭
2. **Client ID** 붙여넣기 → 확인
3. **Client Secret** 붙여넣기 → 확인
4. **`구글 로그인`** 버튼 클릭
5. 브라우저가 열리면 본인 구글 계정 선택 → 권한 허용
   - "확인되지 않은 앱" 경고가 나오면 **고급 → (앱이름)로 이동** 클릭
     (본인이 만든 앱이라 안전합니다)
6. "인증 완료" 페이지가 뜨면 브라우저를 닫고 프로그램으로 돌아오세요
7. 상태가 **연결됨**으로 바뀌고 할일이 이번주 목록에 나타납니다

---

## 이후 동작

- 한 번 로그인하면 **refresh token**이 저장되어 자동 갱신됩니다
- 다시 로그인할 필요 없이, 프로그램 시작 시·30분마다 자동으로 할일을 불러옵니다
- 기한(due date)이 이번주인 할일이 **이번주 목록에 `할일`로 표시**됩니다
- 연결을 끊으려면 **`연결 해제`** 버튼

---

## 저장 위치

```
%APPDATA%\KakaoScheduler\google_oauth.json
```
Client ID·Secret·refresh token이 저장됩니다.
이 파일은 개인 정보이니 공유하지 마세요.

---

## 문제 해결

**"확인되지 않은 앱" 에서 못 넘어감**
→ 3단계의 테스트 사용자에 본인 계정이 등록됐는지 확인

**로그인은 됐는데 할일이 안 보임**
→ 기한(날짜)이 지정된 할일만 이번주 목록에 나옵니다.
   날짜 없는 할일은 표시되지 않습니다 (구글 Tasks 특성).

**"invalid_grant" / 연결 만료**
→ `연결 해제` 후 다시 `구글 로그인`

**브라우저가 안 열림**
→ 기본 브라우저 설정을 확인하거나, 로그인 버튼을 다시 누르세요
