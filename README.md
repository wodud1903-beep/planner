# 일정관리기 + 카카오톡 스케줄러 (Delphi 12 CE)

구글 캘린더 일정을 불러오고, 할일·PC 알람을 관리하며,
카카오톡 예약 발송까지 하나로 묶은 트레이 상주 프로그램입니다.

> ### 🆕 Python 재작성 버전 (`python/` 폴더)
> 직원들이 쓰기 쉽도록 **구글 로그인을 버튼 한 번으로** 바꾸고(캘린더/할일 실시간 API),
> 카카오톡 스케줄러를 제거한 **Python + Qt(PySide6)** 판입니다. 디자인은 그대로 유지했습니다.
> - 실행파일: 저장소 **Releases** / **Actions → Build Windows EXE → Artifacts** 의 `일정관리기.exe`
> - 자세한 내용: **[`python/README.md`](python/README.md)**
>
> 아래는 원본 델파이 버전 설명입니다.

## 📁 구조

메인은 **일정관리기**이고, 카카오톡 스케줄러는 우상단 버튼으로 들어갑니다.

| `uPlanEdit.pas/.dfm` | 할일·알람 편집 창 |
| `uAlarm.pas/.dfm` | 화면 최상단 알람 팝업 |

## 🔧 빌드

1. Delphi 12 CE → `KakaoScheduler.dpr` 열기
2. Target Platform: **Windows 32-bit** 권장
3. **Shift + F9** (Build)

`.pas` 는 UTF-8(BOM)로 저장돼 있습니다. 한글이 깨지면 다시 열어 저장하세요.

## 🖥️ 메인 화면 (일정관리기)

### 탭 1 — 오늘 / 이번주 (구글 캘린더)

1. **구글 캘린더 ICS 주소**를 붙여넣고 `불러오기`
   - 구글 캘린더(웹) → 우측 톱니 **설정**
   - 좌측에서 해당 캘린더 선택
   - **"비공개 주소(iCal 형식)"** URL 복사 → 붙여넣기
2. 오늘 일정과 이번주(7일) 일정이 리스트로 표시됩니다
3. `30분마다 갱신` 체크 시 자동 재조회

> 💡 **구글 할일도 나옵니다.** 단, 할일에 **날짜(기한)를 지정**해야 캘린더에
> 표시되고 이 피드에 들어옵니다. 날짜 없는 할일은 안 나옵니다.
> 시간까지 지정된 캘린더 일정은 그 시각에 알람이 뜹니다.

### 탭 2 — 내 할일 (로컬)

- `추가` → 제목 / 시각 / 알람 여부 / **카톡 멘트** 입력
- 지정 시각에 알람이 뜨고, 알람 창에서 멘트를 복사할 수 있습니다
- `멘트 복사` 버튼으로 언제든 클립보드에 복사

### 탭 3 — PC 알람 (요일 반복)

- `추가` → 이름 / **요일** / 시각 / 멘트
- 지정 요일·시각에 **화면 최상단 팝업**이 뜹니다
- 팝업의 `멘트 복사`로 미리 지정한 문장을 복사 → 카톡에 붙여넣기
- `알람 미리보기`로 팝업 모양을 바로 확인

---

## 🔔 알람 팝업

- 화면 **상단 중앙**에 뜹니다 (항상 위, 포커스 안 뺏음)
- 여러 개가 동시에 뜨면 아래로 쌓입니다
- `멘트 복사` → 클립보드 → 카톡 붙여넣기
- `확인` 또는 `X`로 닫기

---

## 💬 카카오톡 스케줄러

우상단 `카카오톡 스케줄러 열기` 버튼으로 진입합니다.
(기능은 기존과 동일 — 예약 발송, 로그, 채팅방 최소화 등)

창을 닫아도 종료되지 않고 숨겨지며, **예약 발송은 계속 동작**합니다.

---

## 📝 저장 위치

```
%APPDATA%\KakaoScheduler\
  ├─ schedules.json    카톡 예약
  ├─ todos.json        내 할일
  ├─ pcalarms.json     PC 알람
  ├─ config.json       카톡 스케줄러 설정
  ├─ plan_cfg.json     ICS 주소 등
  └─ logs\             카톡 발송 로그
```

## ⚠️ 구글 연동 한계

ICS 방식은 **로그인이 필요 없고 간단**하지만:

- 날짜 없는 구글 할일은 못 가져옵니다 (캘린더에 안 뜨므로)
- 구글이 ICS 피드를 갱신하는 주기가 있어, 방금 추가한 일정은
  즉시 반영이 안 될 수 있습니다 (몇 분~수십 분)

날짜 없는 할일까지 실시간으로 필요하면 구글 OAuth 연동(별도 작업)이
필요합니다. 지금 구조는 대부분의 일정·기한 있는 할일을 커버합니다.

---

## 📌 사용 범위 안내

카카오톡 스케줄러의 자동 발송은 **내부 공지용**입니다.
광고 수신에 동의하지 않은 고객에게 반복 발송하면 카카오 운영정책 위반 및
정보통신망법 저촉 소지가 있으니, 고객 홍보는 카카오톡 채널 + 브랜드 메시지를
이용하세요.

## 🎨 아이콘 파일 (중요)

트레이/작업표시줄 아이콘은 **`PlanManager.ico`** 파일을
**실행파일(.exe)과 같은 폴더**에 두면 프로그램이 실행 시 자동으로 읽습니다.
리소스로 컴파일하지 않으므로 빌드 오류가 나지 않습니다.

- 개발 중: `PlanManager.ico`를 프로젝트 폴더(=exe가 생성되는 곳)에 두세요
- 배포 시: exe와 `PlanManager.ico`를 함께 복사하세요
- 아이콘 파일이 없어도 프로그램은 정상 동작합니다(기본 아이콘 사용)

## 💾 자동 백업

- 프로그램 시작 시, 그리고 매일 날짜가 바뀔 때 자동으로 백업됩니다
- 트레이 우클릭 → **지금 백업**으로 수동 백업도 가능
- 저장 위치: `%APPDATA%\KakaoScheduler\backup\`
  (파일명에 날짜·시각이 붙어 여러 개 보관, 30일 지난 백업은 자동 삭제)
- 백업 대상: 내 할일 · PC 알람 · 카톡 예약 · 설정 전부

## 🚀 PC 시작 시 자동 실행

메인 화면 상단의 **`PC 시작 시 자동 실행`** 체크박스를 켜면,
윈도우 부팅 시 프로그램이 자동으로 뜨고 **모니터 중앙에 표시**됩니다.

- 등록 위치: `HKCU\...\CurrentVersion\Run\PlanManager`
- 체크 해제하면 자동 실행이 취소됩니다
- 부팅으로 실행되면 창이 중앙에 보이고, X로 닫으면 트레이로 들어갑니다
- ⚠️ exe 위치를 옮기면 체크박스를 껐다 켜서 경로를 다시 등록하세요
